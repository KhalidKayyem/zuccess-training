# Logos

Drop the following files into this folder:

- zuccess_logo_without_bg-30.png - horizontal lockup (mark + "ZUCCESS" wordmark + tagline). Used in the top bar on screens sm and wider, and on the certificate.
- zuccess_logo_without_bg-06.png - circular icon (off-white mark on navy circle). Used in the top bar on narrow screens, and as the favicon.
- zahid_logo.png - Zahid Group co-brand lockup (yellow "Z" mark above Arabic and English wordmarks), 608x784, transparent background. Client logo for this demo engagement. Used in the top bar (full lockup on sm+, cropped to just the Z mark on narrow screens), the login screen, and the certificate.

The app references these paths directly and degrades gracefully (falls back to a text wordmark) if a file is missing.
